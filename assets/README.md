# Assets policy

No KolektorSDD2 images, masks, or dataset-derived previews are committed to this repository. Local error-analysis previews are generated under ignored report directories.

`false-alarm-rate.svg` is an original vector chart drawn from aggregate counts and rates documented in `docs/RESULTS.md` and `docs/REFERENCE_METRICS.csv`. It contains no source imagery, masks, per-image identifiers, or model predictions.

This keeps the public code release separate from the dataset's CC BY-NC-SA 4.0 terms. If visual examples are added later, their source, license, and attribution must be recorded beside the files before they are committed.
