# 面試說明指南

## 90 秒版本

我用 KolektorSDD2 建立一套 YOLO11n-seg 工業瑕疵分割流程，工作不只包含訓練模型，也包含 mask 轉 polygon、正式 train/validation/test 切分、資料驗證、五組增強實驗、雙 seed 成對確認、confidence 與 NMS 選擇，以及逐圖錯誤分類。R4 在官方 test 的 mask mAP50 / mAP50–95 是 0.642 / 0.285；固定操作點可定位 75/110 張瑕疵圖，但正常圖誤報率 2.24%，沒有達成原本約 1.20% 的目標，所以我把它定位成完整且可驗證的實驗流程，而不是已可部署的 AOI 系統。

## 面試官追問時要主動說明

- 為何關閉 HSV：固定拍攝條件下，顏色擾動是否合理需要實驗，而不是預設一定有效。
- 為何 mAP 與 operating point 分開：mAP 看整體排序；產線決策需要固定 threshold 下的漏檢與誤報。
- 為何 confidence 寫 0.0975：四捨五入成 0.10 會改變結果，重現時不可混用。
- 為何沒有說可部署：test 的正常圖誤報率超標，而且仍有 40 個 box FN。
- 為何 test 不是完全 unseen：早期探索曾看過同一個官方 test，後來雖凍結流程才正式評估，仍不能稱完全無偏。
- 為何 A1–A4 沒放主線：依賴外部自訂 fork、部分缺少跨 seed 證據，沒有比 R4 更可靠，因此公開版只保留可重現主線。

## 不要使用的說法

- 「模型已達產線標準」
- 「官方 test 完全沒看過」
- 「關閉 HSV 一定比較好」
- 「自訂架構全面優於 baseline」
- 「0.0975 可以直接寫成 0.10」
